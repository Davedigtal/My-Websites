# Kairo Vale - music portfolio landing page

A single-file landing page for a producer and mix engineer portfolio. No build step and no dependencies: open `index.html` in a browser.

## What's in it

- Spinning vinyl hero, live equalizer and a genre ticker
- A working player with five short synthesized loops (Web Audio API, no audio files)
- Illustrated portrait and four audio-art tiles (cassette, mixing desk, spectrogram, wave ring)
- Releases, services, process, live dates and a contact form

## Customize

All copy is plain HTML in `index.html`. The name, bio, prices, dates, venues and email are sample content for a fictional artist, so replace them with real details. The accent colour is `#FF6B35`; search for it to change the palette.

## Host it free

In this repository's settings, go to Pages and publish from the branch. The page will be at `/kairo-vale/`.

The contact form does not send anything yet. Connect it to a form service before using it for real.
